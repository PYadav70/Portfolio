# 🚀 Personal Portfolio

A modern and responsive **full-stack developer portfolio** built with **Next.js, TypeScript, and Tailwind CSS**.  
This portfolio showcases my projects, skills, experience, and contact information with a clean UI and smooth animations.

## ✨ Features

- ⚡ Built with **Next.js 15**
- 🎨 Styled using **Tailwind CSS v4**
- 📱 Fully responsive design
- 🎭 Smooth animations with **Motion**
- 🧩 Reusable UI components
- 🌙 Modern and minimal interface
- 📬 Contact section for collaboration

- **Next.js**
